# Blinkit Power BI Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Blinkit's business and sales performance.

The dashboard provides insights into sales, products, outlet performance, customer-related metrics and other key business indicators.

## 🛠️ Tools Used

* Microsoft Power BI
* Data Visualization

## 📈 Key Areas of Analysis

* Overall Sales Performance
* Product Analysis
* Outlet Performance
* Outlet Type Analysis
* Customer/Rating Analysis
* Key Performance Indicators (KPIs)

## 📂 Project Files

* `Blinkit(Project).pbix` — Power BI dashboard file
* `screenshots/` — Dashboard screenshots

## 🎯 Objective

The objective of this project is to transform raw business data into an interactive dashboard and generate meaningful insights that can support business decision-making.
